# Projektüberblick

## Ziel

Eine übersichtliche Landingpage für ein Bestattungsunternehmen. Die Arbeitsprobe zeigt, wie Besucher Leistungen kennenlernen und ein persönliches Gespräch anfragen können.

## Aufbau

Start → Ablauf → Leistungen → Kundenstimmen → Zusammenarbeit → Kontakt → Standort.

„Termin vereinbaren“ führt zur Kontaktsektion. Dort können Besucher ihr Anliegen über das Formular vorbereiten oder die vorgesehene Calendly-Buchung nutzen. Die Routenplanung öffnet Google Maps mit der angezeigten Adresse.

## Gestaltung

Die Seite verbindet ruhige Grüntöne, PT Sans und Bebas Neue mit dem bereitgestellten AlsterCloud-Logo. Desktop und mobile Darstellung folgen derselben Struktur. Karussells und animierte Navigation unterstützen die Orientierung.

## Umsetzung und Umfang

React und Vite ermöglichen eine statische Veröffentlichung über GitHub Pages. Für diese Arbeitsprobe sind kein CMS, keine Nutzerkonten und keine Datenbank vorgesehen.

Das Formular übergibt die Nachricht an das E-Mail-Programm. Für einen echten Kundeneinsatz sind direkter Versand, Calendly sowie finale Inhalte, Profilziele und rechtliche Angaben zu ergänzen. Eine abschließende Prüfung auf Desktop und Smartphone steht noch aus.
